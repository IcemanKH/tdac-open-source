# 泰国电子入境卡（TDAC）填写助手

**简体中文** | [English](README.en.md)

> **非官方、免费、开源**的泰国电子入境卡（Thailand Digital Arrival Card, TDAC）辅助填表工具，
> 目前处于 **Beta 阶段**。
> 本工具与泰国政府及移民局**无任何隶属关系**。官方入口：<https://tdac.immigration.go.th/arrival-card/>

---

## 这是什么

在你**自己的电脑**上，用你**已经装好**的 Chrome 或 Edge，**尝试自动预填** TDAC 入境卡表单，
然后停在预览页，让你逐项核对。

它**不会替你提交**。最终阅读条款、勾选同意、点击 Submit、拿到回执，这些**必须由你本人完成**。

> **Beta 提示：** 自动预填能力目前**只在离线环境验证过**，**真实官网的端到端流程尚未验收**，
> 因此它**不是**一个「已验证稳定」的能力。请抱着「可能会失败、失败就改回手动填写」的预期使用。

> ### ⚠️ 预填完成 ≠ 已成功申报
>
> 程序停在预览页就结束了。你必须自己在官网上核对每一项、勾选法律条款、点击 Submit，
> 并保存官方回执。**程序永远不会替你做这一步，也无法替你确认申报是否成功。**

## 适合谁用

**适合你，如果你同时满足：**

- 使用 **Windows 11 64 位**，电脑上已装 Chrome 或 Edge；
- 持**中国普通护照**，**航空入境**泰国，目的是**旅游**，住**酒店**（首版覆盖的常见单人场景）；
- 愿意自己在官网上核对并提交，只是不想手动把几十个字段一个个敲进去；
- 能接受这是 **Beta 测试版**，出问题时愿意放弃并改为手动填写。

**不适合你，如果你：**

- 期望它"一键搞定、自动提交拿到回执"——**它不做这件事**；
- 使用 Windows 10 / macOS / Linux，或是多人团体、陆路/海路入境（首版未承诺）；
- 不愿意自行承担核对责任，或希望由软件保证申报成功。

## 使用限制（Beta，请务必读完）

- **这是 Beta 测试版，不是稳定正式版。**
- **真实官网的完整流程尚未验收。** 目前所有验证都在**离线**环境完成（配置校验、字段映射、
  必填清单、日志脱敏、离线演练、图形界面一致性、便携版启动）。真实日期窗口、真实航班号回显、
  住宿府/区/分区级联、预览页邮箱、提交后的官方回执，都必须等申报窗口开放后由本人实测。
  **离线通过不代表能在真实官网一次成功。**
- 首版**仅支持**：Windows 11 64 位、**单人**申报、中国普通护照、航空入境、旅游目的、酒店住宿。
- 申报受官网**抵达前 3 天**窗口限制；窗口未开时程序会明确提示并阻止正式预填。
- 程序**不自动提交**、**不自动勾选法律条款**、**不绕过**验证码 / 风控 / 官网日期窗口、
  **不猜测**健康声明答案（缺值即停止）、不向第三方上传资料、预览 PDF 默认不生成。
- 每次开始正式预填前，程序都会要求你**当次**核对关键身份字段、行程住宿与健康声明；
  任何资料改动都会使本次授权失效。
- 本项目为业余维护，不保证修复响应时效。

## 快速上手（免安装便携版）

### 1. 下载

从本仓库的 **Releases** 页面下载 `TDAC填写助手-<版本>-windows-x64.zip`
（例如 `TDAC填写助手-0.1.0-windows-x64.zip`），同目录提供
`TDAC填写助手-<版本>-windows-x64.zip.sha256` 校验文件。

### 2. 校验完整性（建议）

未签名的程序可能触发 Windows SmartScreen 提示。请只从本项目官方 GitHub Releases 下载，
并自行核对发布页列出的 SHA-256。PowerShell 示例：

```powershell
Get-FileHash .\TDAC填写助手-0.1.0-windows-x64.zip -Algorithm SHA256
```

结果应与发布页及同名 `.sha256` 文件中记录的值一致。

### 3. 解压并启动

- **解压后必须保留整个 `TDAC填写助手` 目录**，不能只把 EXE 单独复制出来。
- 双击其中的 `TDAC填写助手.exe` 即可打开简体中文图形界面。
  **无需安装 Python**，不需要管理员权限，中文目录可正常启动。

### 4. 录入资料

- 按界面分页 **个人资料 / 行程与住宿 / 健康声明 / 开始填写 / 工具 / 关于** 逐页填写；
- 护照号、手机号、收件邮箱保存前会做**格式校验 + 二次确认**；
- 这三项**默认以 `*` 遮挡**，只有你点击「显示」才会看到完整内容；
- 没填完可以先点顶部 **「暂存草稿（资料可暂不完整）」**，下次打开会自动恢复继续编辑。

### 5. 开始填写

在「开始填写」页有两个按钮：

- **离线演练（不触网）**：完全合成资料，不启动浏览器、不联网，用于检查本地逻辑；
- **开始正式预填（打开官网）**：通过校验后打开真实官网自动预填。

运行中可以**暂停 / 继续**，或**停止并转人工接管**。到达预览页后程序会输出**脱敏**核对清单并停下，
**由你本人复核、勾选条款、点击 Submit 并保存回执**。

### 6. 换一次旅行要改什么

只需在「行程与住宿」页更新本次行程（入境/离境日期、航班号、住宿信息），保存后重新开始即可。

## 数据保存在哪里、如何删除

- 用户数据位于**当前 Windows 用户的专属数据目录** `%LOCALAPPDATA%\TDAC\`
  （配置 `config\`、密文 `secrets\`、浏览器资料 `browser_profile\`、日志 `logs\`、输出 `output\`），
  **与程序目录分离**——替换或升级程序不会覆盖你的资料。
- 护照号与手机号使用 **Windows DPAPI** 加密（与当前 Windows 用户 + 本机绑定）；
  草稿中的敏感字段用**同一套 DPAPI** 存到独立文件，`draft.json` 内不含任何敏感明文。
  换 Windows 账户或换电脑后**无法解密**，需要重新录入。
- 日志默认脱敏：护照号、手机号、邮箱、航班号、邮编、地址均不写入完整值。
- 界面中的敏感字段默认以 `*` 遮挡，只有你主动点击「显示」才会展示完整内容；
  程序**不会**在后台自动揭示完整值。
- 预览 PDF 仅在你主动选择导出时生成，内容可能含完整个人资料，请按敏感文件保管。

**删除数据：**

- 图形界面：「工具」页 → **「删除受管用户资料…」**（会明确确认）；
- 命令行：`python tdac_fill.py --delete-data`（交互确认；加 `--yes` 可跳过）。

两者都会清理配置、密文、草稿、浏览器资料、日志与输出，且删除前会校验目标确实位于受管数据目录内。

## 命令行用法（进阶 / 排查）

便携版用户一般不需要这些；源码运行方式见下方开发者章节。

```
python tdac_fill.py --gui            # 启动简体中文图形界面
python tdac_fill.py --check          # 仅做环境与配置检查（不打开浏览器）
python tdac_fill.py --dry-run        # 离线检查：完全合成资料，不启动浏览器、不触网
python tdac_fill.py --smoke          # 同 --dry-run：完全合成资料，不启动浏览器、不触网
python tdac_fill.py                  # 正式流程（受抵达前 3 天窗口限制，会打开官网）
python tdac_fill.py --inspect        # 打开官网并导出当前表单字段清单（排查用）
python tdac_fill.py --export-pdf     # 预览校验通过后导出 PDF（可选，含敏感资料）
python tdac_fill.py --pdf-path PATH  # 指定 PDF 保存位置
python tdac_fill.py --session-info   # 只读查看会话与调试端口说明、残留检测
python tdac_fill.py --export-diagnostic   # 导出脱敏诊断包（白名单，可供排查）
python tdac_fill.py --check-update   # 经你同意后检查可配置的版本来源
python tdac_fill.py --close-browser  # 结束后关闭本程序启动的浏览器实例（不影响你日常用的 Chrome）
python set_secrets.py                # 录入护照号 / 手机号（加密保存，不回显）
python tdac_fill.py --delete-data    # 删除本程序管理的用户数据
```

> `--smoke` 与 `--dry-run` 一律**离线**：使用完全构造的合成资料，不读取真实配置、
> 不启动浏览器、不访问泰国官网，因此**不可能**触发任何正式提交或虚假申报。
> 当前版本**不提供**自动化的"官网交互测试模式"；任何会访问真实官网的测试都必须另行单独授权。

> **版本检查**只在你在界面点击（或显式运行 `--check-update`）时才联网，只读取版本号与官方下载页，
> **不自动下载、不自动安装、不远程执行代码**。版本来源可配置（`config/update.json` 或环境变量
> `TDAC_UPDATE_SOURCE`），默认**未预置任何地址**。

> **脱敏诊断包**只包含白名单中的非敏感元信息（版本、平台、布尔存在性等）。由你主动导出、
> 可先预览再自行决定是否发送；**不含**姓名、护照、手机号、邮箱、行程、浏览器凭据、
> 网页截图或网页源码。导出前会自检，命中敏感模式即拒绝导出。

## 开发者章节

以下内容面向想阅读源码、自行构建或审计的人。普通用户**不需要**阅读这一节。

### 工作原理

- **浏览器自动化**：以你本机已安装的 Chrome/Edge 启动一个**独立用户目录**的可见浏览器，
  由 **Playwright 通过 CDP** 接管；不捆绑浏览器。会话使用独立用户目录 + 随机**回环**调试端口，
  启动前做只读残留检测；**绝不使用**会扩大远程调试访问范围的参数（如 `--remote-allow-origins=*`）。
  检测不到 Chrome / Edge 时给出中文说明与官方下载入口，**不自动安装、不修改系统默认浏览器**。
- **敏感字段加密**：护照号 / 手机号用 **Windows DPAPI**（`CryptProtectData`）加密，
  密钥与当前 Windows 用户 + 本机绑定；写入后尽力收紧 ACL 为仅当前用户可读写。
- **图形界面**：Python 标准库 **tkinter**，不引入额外 GUI 框架。
- **便携版打包**：PyInstaller **onedir**，普通用户无需安装 Python。
- **预填门禁**：界面、命令行与便携版 EXE 共用**同一套**门禁，不存在"跳过确认"的开关。
  门禁要求：资料完整 + 格式正确 + 关键字段在**本次正式预填**中由本人确认 + 处于申报窗口内
  + 健康声明在本次使用中已重新确认。关键字的授权同时绑定行程、住宿与健康答案的指纹，
  任一字段改动都会使当次授权失效。
- **网络边界**：不向任何第三方服务器发送资料；仅正式预填与（你主动发起的）版本检查会联网。

### 从源码运行

```powershell
python -m venv .build\venv
.build\venv\Scripts\python.exe -m pip install -r requirements.txt
.build\venv\Scripts\python.exe tdac_fill.py --gui
```

需要构建依赖（PyInstaller）时另装 `requirements-build.txt`。
首次运行会按 `templates\config\*.example.json` 在用户数据目录生成配置模板（不覆盖已有文件）。
可用环境变量 `TDAC_DATA_DIR` 覆盖数据目录（便携 / 测试场景）。

### 构建便携版

```powershell
.build\venv\Scripts\python.exe build_portable.py
```

### 运行测试（全部离线）

```powershell
.build\venv\Scripts\python.exe -m unittest discover -s tests -v
```

### 公开发布流程

```powershell
# 1) 生成干净发布暂存目录并做脱敏扫描
.build\venv\Scripts\python.exe tools\prepare_release.py
# 2) 由同一次构建产物打包发行 ZIP 并输出其 SHA-256
.build\venv\Scripts\python.exe tools\make_release_zip.py
```

`tools/prepare_release.py` 采用**白名单**机制：只有明确列出的文件/目录才会进入发布暂存目录，
并对结果做脱敏扫描（私有绝对路径、真实邮箱 / 手机号 / 护照号、密文、日志、截图等命中即失败）。
`tools/make_release_zip.py` 只在**同一次构建内**由该次 onedir 产物现场打包，绝不从开发机上传现成 ZIP；
打包后会回读 ZIP 逐文件比对。

### 目录结构

```
tdac-open-source/
├─ tdac_app.py             便携版单一入口（双击 → 图形界面；带参数 → 命令行）
├─ tdac_gui.py             简体中文图形界面（tkinter）
├─ tdac_fill.py            主流程：检查、填写、健康、预览、导出
├─ tdac_group.py           团体资料模型（首版不对外承诺多人）
├─ tdac_sec.py             Windows DPAPI 加密资料读写
├─ tdac_paths.py           程序/用户数据目录分离与安全删除
├─ tdac_privacy.py         日志脱敏 + 关键字段二次确认
├─ tdac_validate.py        护照号 / 手机号 / 邮箱格式校验 + 正式预填门禁
├─ tdac_draft.py           本地草稿暂存（一份草稿；敏感字段走 DPAPI）
├─ tdac_gate.py            预填授权门禁（关键字段 + 行程住宿 + 健康答案指纹绑定）
├─ tdac_browser.py         浏览器检测、缺失引导、会话与调试端口
├─ tdac_update.py          可配置版本检查
├─ tdac_diag.py            脱敏诊断包
├─ tdac_synth.py           完全合成的测试资料
├─ set_secrets.py          不回显录入护照号/手机号
├─ build_portable.py       PyInstaller onedir 便携版构建脚本
├─ tools/prepare_release.py         生成干净发布暂存目录（白名单 + 脱敏扫描）
├─ tools/make_release_zip.py        由同次构建产物打包发行 ZIP 并输出其 SHA-256
├─ config/group.example.json        团体配置模板
├─ templates/config/*.example.json  首次运行的用户配置模板
├─ templates/TDAC_同行人必填信息表_template.csv
├─ docs/images/            界面截图（纯合成资料，已脱敏）
├─ tests/                  离线单元测试
├─ requirements.txt        锁定的运行时依赖版本
└─ .github/workflows/build.yml      公开构建工作流
```

### 持续集成

`.github/workflows/build.yml` 在 GitHub 托管的 Windows runner 上执行：
安装锁定依赖 → 全量离线单元测试 → 源码语法自检 → 离线演练 → 生成发布暂存目录并脱敏扫描
→ PyInstaller 构建 → 由该次产物打包发行 ZIP + 校验文件 → 逐文件回读复核 → 上传构建证据。
CI 会把 `github.sha` 注入构建元数据（`BUILD_INFO.json` 的 `vcs.commit`），
用于证明 ZIP 确实来自该次提交的公开构建。
